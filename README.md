## 摘要

自动气象站长期运行于野外，受设备故障、通信中断和恶劣天气影响，数据缺测十分普遍，缺测率可达 5%–15%，个别站点超过 30%。缺测数据若直接进入天气预报与行业决策流程，会显著降低结果可靠性。现有处理方法存在明显短板：均值填充与线性插值实现简单但误差大，连续缺测时基本失效；KNN 与随机森林精度有所提升但模型体积偏大、部署不便；以 LSTM 为代表的深度模型精度较高，然而多数研究只关注精度指标，忽视了模型能否在普通设备上快速运行这一业务上更实际的问题。

本作品面向"模型要小而准"这一核心诉求，构建了一套轻量化多变量联合插补方案。模型主体由三个组件构成：以站点经纬度构建的**站点空间图**、以变量间物理相关性初始化并可学习的**变量物理图**，以及以深度可分离膨胀卷积实现的**时序特征提取器**。三者的组合在 10 万参数量预算内实现了多站点、多要素的联合插补。

在真实逐小时气象数据（NASA POWER，2025 年 8 月 21 日–9 月 20 日，华北 8 站 6 要素，744 小时）上，本方案在 MAE、RMSE、R² 三项指标上全面优于线性插值、KNN 及同参数规模的 LSTM 基线。其中 R² 达到 **0.9593**，较同参数量 LSTM（0.8528）提升 0.107；MAE 为 **6.07**，较 LSTM（9.67）降低 37%；参数量 15,661，控制在 10 万预算的 16% 以内。

本方案在实现过程中通过逐项消融实验定位并修复了一个关键的结构缺陷：原版空间图采用标准加权平均聚合，导致本站信号被邻站稀释（自环权重仅 0.274，即 72.6% 的信息来自邻站）。改为残差式聚合后，R² 由 0.6837 提升至 0.9593。这一修复过程及其可解释性证据（各层邻站注入强度 β 的层级规律）构成了本作品在方法论上的主要贡献。

**关键词**：缺测数据插补；图神经网络；深度可分离卷积；多变量联合建模；轻量化模型

## 一、作品概述

### 1. 背景介绍

气象要素的精细化观测是智慧气象体系的基础环节。自动气象站作为最贴近地表的观测手段，广泛分布于校园、城市监测点、野外新能源电站和应急指挥车等场景。

但气象站长期运行在野外，受设备故障、通信中断、恶劣天气等影响，数据缺测十分普遍。缺测数据如果直接使用，会影响天气预报的准确性和行业决策的可靠性——例如极端天气过程中关键站点数据缺失，就可能直接影响预警的及时性。

从技术视角看，气象缺测数据插补面临三个层面的挑战：

1. **时空耦合性**。气象要素在时间上具有显著的日变化周期与季节趋势，在空间上具有站点间相关性。孤立地对单个站点、单个变量建模会丢失这些结构信息。
2. **连续缺测的难度**。随机单点缺测可由简单的插值方法解决，但设备宕机导致的连续几十小时缺测，会使插值方法在缺口中间退化为直线连接，误差随缺口长度迅速增长。
3. **算力约束**。业务场景中的模型常需部署于校园气象站、野外台站、应急指挥车等边缘节点，往往不具备 GPU，对模型体积与推理延迟有严格要求。

### 2. 目标定位

本作品的总体目标是：构建一套精度高、模型小、可解释的缺测数据智能插补方案。具体包括：

1. 插补精度优于线性插值、KNN 等传统基线方法，并与**同参数规模**的 LSTM 模型进行对比，验证模型结构设计的优势；
2. 模型参数量控制在 10 万以内，单窗口 CPU 前向推理耗时控制在毫秒级；
3. 利用温度、比湿、风速、气压之间的关联关系联合插补，连续缺测时也能保持稳定精度；
4. 输出可解释的中间结果（空间图权重、变量图边权、层级注入强度），使模型决策过程可被审视；
5. 为后续融入气象物理规律约束预留可插拔的工程接口。

**关于置信区间功能的说明**：在方案论证阶段曾规划"每个插补值附带置信区间"，但经评估认为该功能属于锦上添花，且会增加模型复杂度与训练不稳定风险。经确认，该功能已从最终方案中移除，代码中不实现也不预留相关模块。

**典型应用场景**包括：校园气象站、城市环境监测点、野外新能源电站、应急指挥车等数据容易中断的环境。

### 3. 作品创新点

**创新点一：多变量联合插补。**
温度、比湿、风速、气压、降水、辐射之间是相互关联的。本作品不是孤立地补一个变量，而是把多个变量放在一起联合分析：以训练段变量间 Pearson 相关系数为先验初始化一张"变量物理图"，在训练中让边权继续可学习，实现"数据驱动地修正物理先验"。这样即使某个变量缺测严重，其他变量也能提供信息。

**创新点二：轻量化卷积结构设计。**
模型主体采用深度可分离膨胀卷积提取时间特征。需要说明的是，小规模 LSTM 的体积同样不大，因此本作品的优势不在于"LSTM 跑不动"，而在于**在相同参数预算下，通过卷积结构获得更好的精度**。这一点已通过与同参数规模 LSTM（15,959 vs 15,661，偏差 +1.90%）的对照实验验证：MAE 降低 37.3%，R² 提升 0.1065。

**创新点三：空间图聚合方式的修正——从"稀释"到"增量"。**
这是本作品在实施过程中通过消融实验发现并解决的关键问题，也是方法论上的主要贡献：
标准图卷积采用行归一化的加权平均聚合（`h = A_s @ h`），在本任务中导致**自环权重仅 0.274**，即每次聚合有 72.6% 的信息来自其他站点。而所选 8 个站点相距 110–1056 km，在 72 小时窗口内各站温度走势由日变化主导、站间气温相关中位数 0.86，邻站提供不了新信息，只是稀释了本站信号。
本作品将其改造成残差式聚合：`h = h + β · (A_s @ h − h)`，其中 β 为可学习标量。**本站特征保留 100%，邻站仅做增量修正**。β 的可学习性带来一个重要性质：若邻站确实无用，模型会把 β 压向 0，自动退化为无空间图；反之则主动加大利用强度。这比人工二选一地决定"用/不用空间图"更为稳健。
实测 R² 由 0.6837 提升至 0.9593，且仍优于"完全去掉空间图"的消融结果（0.9534）——说明空间图确有价值，原问题仅在于聚合权重的分配方式。

**创新点四：可解释性产出。**
模型训练后可输出三类可解释性证据：站点空间图权重、学习到的变量物理图边权、以及各层邻站注入强度 β。其中 β 呈现出清晰的层级规律（浅层利用邻站、深层依靠自身），表明模型自主学会了"何时该看邻站、何时不该看"，无需人工设计。

**创新点五：为物理规律约束预留可插拔架构。**
将气象物理约束实现为注册表机制（`PHYS_REGISTRY` + 装饰器），新增约束只需编写函数并注册一行，无需改动主干代码，也不影响已有实验的可复现性。当前启用了时间平滑约束，另有日变化周期、干湿一致性、风速非负三项约束留有函数骨架，待消融实验验证后决定是否纳入。

## 二、需求分析

### 1. 问题剖析

本作品聚焦的核心问题是**多站点、多要素、连续缺测条件下的气象数据插补**。基于对公开气象数据质量与业务场景的分析，归纳出以下四点核心挑战：

1. **时空结构依赖**。气象要素具有明显的日变化周期与站点空间相关性。单变量、单站点建模会丢弃这两类结构信息，在连续缺测时表现尤为明显。
2. **连续缺测的补偿需求**。真实业务中的缺测往往成段出现（设备宕机、通信中断），此时插值方法在缺口中间只能生成连接两端的直线，无法反映真实的气象演变过程，必须依赖其他变量与邻站信息进行补偿。
3. **资源与实时性约束**。模型需部署于边缘节点，对参数量、推理延迟和内存占用有严格限制，传统大型深度模型难以满足。
4. **结果可解释性要求**。插补结果若直接用于业务决策，用户需要理解模型"依据什么做出判断"。全黑箱模型不利于建立信任。

### 2. 需求调研

围绕上述问题，本作品开展了以下调研工作：

1. **文献与技术调研**。检索并研读缺测数据插补、图神经网络、多变量时序建模等方向的代表性工作，重点分析均值填充、线性插值、KNN、随机森林、LSTM 等方法的适用边界与性能特征。
2. **数据质量调研**。查阅气象观测规范与数据质量评估文献，明确缺测率的典型分布（5%–15%，个别超 30%）、缺测的主要成因（设备故障、通信中断、恶劣天气）以及连续缺测的典型时长。
3. **部署环境调研**。结合校园气象站、野外新能源电站等场景，明确边缘设备的算力约束，确定 10 万参数量作为模型规模的控制目标。

### 3. 应用场景与用户需求

**典型应用场景**：

1. **校园气象站**：为教学与科研提供连续完整的气象数据序列。
2. **野外新能源电站**：为风光互补电站的历史数据修复提供支撑，服务于功率预测与能源调度。
3. **城市环境监测点**：修复空气质量与气象监测数据的缺测段，支撑环境分析与城市管理。
4. **应急指挥车**：在离线或断网场景下，利用车载低功耗设备完成数据修复与质量评估。

**用户需求**主要体现在三个方面：

1. 希望在连续缺测条件下仍能获得准确、稳定的插补结果；
2. 希望模型体积小、推理快，易于在现有设备上部署；
3. 希望通过可视化结果（插补曲线、空间图、变量图）直观理解模型输出与判断依据。

## 三、AI 技术工具选择与运用

本章从总体技术路线、核心模型设计、训练策略和开发工具四个方面介绍本作品的技术方案。整体技术路线可概括为四个步骤（记为 S1–S4）：

1. **步骤 S1：数据获取与质量检查**。从公开气象数据平台获取逐小时多要素观测数据，统一变量定义与单位，记录并报告原始缺测率。
2. **步骤 S2：图结构构建**。基于站点经纬度构建高斯核空间图；基于训练段变量间相关性构建变量物理图。
3. **步骤 S3：图-卷积联合建模与训练**。以缺失掩码与人为挖缺模拟真实缺测场景，训练深度可分离膨胀卷积编码器，输出完整插补场。
4. **步骤 S4：评测、消融与可解释性分析**。在统一掩码下与三类基线对比，开展逐项消融定位各模块贡献，导出可解释性证据。

### 1. 步骤 S1：数据获取与质量检查

**数据来源**。本作品提供两条数据通道，可通过 `--source` 参数切换：

| 通道 | 参数值 | 说明 |
|---|---|---|
| NASA POWER 逐小时 | `power_hourly` | 免鉴权、格式稳定，实测可用。本质是 MERRA-2 的服务化产品，但只暴露部分变量 |
| NASA MERRA-2 原生 | `merra2` | 0.5°×0.625° 逐小时，变量集更全（含比湿、气压），需 Earthdata 账号 |

**变量清单**（6 个要素，均为逐小时）：

| 变量 | 物理含义 | 单位 | 在多变量联合中的作用 |

| T2M | 2m 气温 | K | 与比湿、气压存在热力学耦合 |
| QV2M | 2m 比湿 | kg/kg | 反映水汽含量，与温度强相关 |
| WS10M | 10m 风速 | m/s | 由 U10M/V10M 矢量合成 |

| PRECTOTCORR | 降水 | mm/hr | 水循环环节，与湿度相关 |

**站点清单**（华北地区 8 站，站间距 110–1056 km）：

**数据质量处理原则**。本作品在数据环节遵循一条严格原则：**任何数据获取失败都必须明确报错并终止程序，禁止静默降级**。

具体实现为：下载失败时抛出 `DataSourceError`，打印具体的错误原因与排查建议，随后以退出码 2 终止，**不产生任何结果文件**。设计动机是：报告中的每一个数字都必须来自真实数据，使用合成数据产生的指标属于学术不端。若确需跑通流程，必须显式指定 `--allow_synthetic`，此时输出文件名会自动附加 `.SYNTHETIC` 后缀、图标题会打印警告横幅，确保不与真实结果混淆。

此外，缓存文件（`raw_cache.npz`）中记录了数据指纹（数据源、时段、站点、变量、版本号）。任一参数变化都会使指纹失配，缓存自动失效并重新下载，杜绝"修改了配置却仍读取旧数据"的问题。

### 2. 步骤 S2：图结构构建

**（1）站点空间图**

以站点经纬度计算球面大圆距离，经高斯核转换为邻接权重：

$$A_{ij} = \exp\left(-\frac{D_{ij}^2}{2\sigma^2}\right)$$

其中 $D_{ij}$ 为站点 $i,j$ 间大圆距离，$\sigma$ 为带宽（默认 350 km）。随后进行弱边截断（权重 < 0.15 置零）与行归一化。

带宽 $\sigma$ 的选取需要与站点间距匹配。构建函数内置了诊断输出：非零边占比过低（< 10%）提示带宽过小导致图退化为孤岛；接近 100% 提示带宽过大导致图退化为简单平均。

**（2）变量物理图**

以训练段各变量间的 Pearson 相关系数绝对值作为初始边权，即"物理相关先验"。例如温度与比湿正相关、气压与温度弱相关，这些关系由数据自身给出，而非人工设定。训练过程中，边权作为可学习参数继续调整，实现数据驱动地对物理先验进行修正。

### 3. 步骤 S3：图-卷积联合建模

**（1）模型总体结构**

模型输入为一段多变量历史观测加上缺测位置标记，输出为完整插补场。对于输入 $x \in \mathbb{R}^{B\times L\times N\times C}$ 与掩码 $m$，前向过程为：

$$x_v = A_v \cdot x \qquad \text{（变量物理图消息传递）}$$
$$h = W_e [x \odot m,\ m,\ x_v \odot m] \qquad \text{（特征嵌入，} W_e \in \mathbb{R}^{3C\times H}\text{）}$$
$$h^{(l+1)} = \text{STBlock}^{(l)}(h^{(l)}, A_s), \quad l = 0,\dots,L_{\text{layers}}-1$$
$$\hat{y} = W_o h^{(L_{\text{layers}})} \qquad \text{（输出投影）}$$

其中 $A_v$ 为变量物理图（可学习），$A_s$ 为站点空间图（固定 buffer），$\text{STBlock}$ 为时空块。

**创新点三的实现——时空块中的空间聚合**

时空块先执行空间聚合，再执行时间卷积。空间聚合提供两种模式：

**模式 A：加权平均（`--spatial_mode avg`，原版）**
$$h \leftarrow A_s h$$

**模式 B：残差式（`--spatial_mode residual`，默认）**
$$h \leftarrow h + \beta \cdot (A_s h - h)$$

其中 $\beta \in \mathbb{R}$ 为可学习标量，初始值 0.1。模式 B 的物理含义是：**本站特征为主体（保留 100%），邻站信息作为增量修正**。

采用模式 B 的原因：模式 A 的邻接矩阵经行归一化后，**自环权重均值仅 0.274**，即每次聚合有 **72.6% 的信息来自其他站点**，本站在特征里只占 27.4%（该诊断值在每次运行时由 `build_station_graph` 打印）。而所选站点相距 110–1056 km，72 小时窗口内各站温度由日变化主导、站间气温相关中位数 0.86，邻站无法提供有效的新信息，只会稀释本站信号。

消融实验直接印证了这一结构性缺陷：把聚合方式从模式 A 改为模式 B，**R² 由 0.6837 提升至 0.9593（ΔR² = +0.2756）**，是所有改动中影响最大的一项，量级是其他消融项的 4~900 倍（详见 §5.3）。

模式 B 的关键优势在于 $\beta$ 的可学习性：若邻站确实无用，梯度会将 $\beta$ 推向 0，模型自动退化为无空间图；若邻站有信息价值，则 $\beta$ 会增大。这使"是否使用空间信息"由数据自主决定，而非依赖人工试错。

**时间特征提取：深度可分离膨胀卷积（DSC）**

深度可分离卷积将标准卷积分解为深度卷积（depthwise，每通道独立）与逐点卷积（pointwise，1×1 混合通道），参数量约为标准卷积的 $1/H$，是轻量化的核心手段：

$$\text{DSC}(u) = \text{GELU}\big(\text{GroupNorm}(\text{PW}(\text{DW}(u))) + u\big)$$

其中 DW 为深度卷积（含膨胀，用于扩大感受野），PW 为逐点卷积，残差连接缓解深层网络的梯度问题。各层膨胀率依次为 $2^l$（1, 2, 4, ...），形成指数增长的多尺度感受野。

**（2）缺失模拟机制**

训练与评测采用"人为挖缺"模拟真实缺测场景，包含两种模式：

- **MCAR 随机缺失**：每个元素以概率 $p_{\text{mcar}}$（默认 0.15）独立缺失，模拟单点随机异常；
- **连续缺测段**：以概率 $p_{\text{block}}$（默认 0.30）在随机位置生成长度 2 至 $L_{\text{max}}$ 的连续缺失段，模拟设备宕机与通信中断。

**关键参数约束**：$L_{\text{max}}$（`--block_maxlen`）不得超过窗口长度 $L$ 的 50%。若违反，窗口内将只剩 1–2 个锚定观测点，任务本质会从"插补"退化为"无中生有"，任何模型都只能输出直线——这是任务设置失真而非模型能力问题。代码中已加入硬校验拦截此配置，并给出修复建议。

### 4. 步骤 S4：训练策略与损失设计

**损失函数**由三项构成：

$$\mathcal{L} = \mathcal{L}_{\text{eval}} + 0.5 \cdot \mathcal{L}_{\text{in}} + \sum_k \lambda_k \mathcal{L}_{\text{phys}}^{(k)}$$

1. $\mathcal{L}_{\text{eval}}$：**缺口处主损失**，仅在人为挖缺位置计算，是模型优化的主要目标；
2. $\mathcal{L}_{\text{in}}$：**观测点重构约束**，在已观测位置计算，防止模型在填补缺口时破坏已有的观测信息；
3. $\mathcal{L}_{\text{phys}}^{(k)}$：**物理规律约束**，当前启用时间平滑项。

**物理规律约束的可插拔设计**

物理约束被实现为注册表机制。定义一个约束只需编写函数并注册：

```python
@register_physics("time_smooth", default_weight=0.05)
def phys_time_smooth(pred, tgt, m_eval, ctx):
    diff = (pred[:, 1:] - pred[:, :-1]).abs()
    pm = m_eval[:, 1:] * m_eval[:, :-1]
    return (diff * pm).sum() / (pm.sum() + 1e-8)
```

**当前已注册的四项约束**：

| 约束名 | 状态 | 物理依据 |
|---|---|---|
| `time_smooth` | **已启用**（权重 0.05） | 气温/气压/湿度在 1 小时尺度上的变化率有物理上限，不应出现剧烈跳变 |
| `diurnal_cycle` | 骨架（权重 0） | 约束插补序列的 24h 周期形状接近气候态 |
| `humidity_consistency` | 骨架（权重 0） | 温度与比湿的耦合关系（Clausius-Clapeyron 方向） |
| `wind_nonneg` | 骨架（权重 0） | 标量风速物理上不可能为负 |

后三项目前为函数骨架，调用时抛出 `NotImplementedError`。这是刻意的设计：**约束是否有效必须通过消融实验验证，不能先写死再寻找理由**。骨架中已记录了实现思路与风险提示（例如日变化约束对降水可能有害，必须分子变量给定权重）。

**训练配置**：优化器 Adam，学习率 2e-3，批大小 16，梯度裁剪阈值 5.0，早停耐心值 12 个 epoch。数据按时间顺序 7:1.5:1.5 划分为训练/验证/测试集，**严格避免信息泄露**。

### 3. 关键技术实现

**（1）跨脚本参数契约**

主程序的 `build_station_graph`、`run_epoch` 等函数会直接访问 `args` 的多个属性。跨脚本复用时，只要调用方的 `argparse` 少定义一个字段，就会抛出 `AttributeError`。更隐蔽的陷阱是：若补全代码写在函数调用**之后**，错误依然会发生，因为属性在调用时就被读取了。

为此主程序提供 `fill_missing_args(args)` 统一入口，并确立一条铁律：**任何调用主程序函数的脚本，必须在 `parse_args()` 之后的第一件事就调用它**。这条规则已在三个脚本的注释中明确标注。

**（2）窗口数与参数合法性守卫**

在切分样本前校验窗口数量，避免程序运行到训练循环才崩溃：

- 窗口数少于 10 个时直接退出，并打印窗口数计算公式与三种修复方案（调小窗口、调小步长、拉长时间范围）；
- 校验 7:1.5:1.5 划分后三段均非空；
- 校验 `block_maxlen ≤ 0.5 × window`（违反时抛 `ValueError` 并给出修复建议，因为否则会造出"一个窗口里几乎全是缺口"的退化样本，任务从插补变成无中生有）；
- 校验 `window ≥ 2`、`stride ≥ 1`；
- 提示 `window` 是否为 24 的整数倍（影响日变化分析的相位对齐）。

**（3）逐小时数据的窗口相位对齐**

滑动窗口切分时，窗口内第 0 个点对应的真实钟点是随时间变化的。若直接使用窗口内局部下标（0…L−1）做日变化统计，不同相位的窗口会被混合平均，导致日变化曲线出现假性相位滞后。

因此 `make_windows()` 返回三元组 `(Xw, Mw, start_idx)`，其中 `start_idx` 记录每个窗口在原始序列中的起始时刻。日变化分析使用 `(start_idx + i) % 24` 计算真实钟点，确保相位正确。

**（4）可解释性工程钩子**

- `--dump_aux`：推理时导出中间张量（嵌入特征、变量图边权），供后续归因分析；
- `model.record_aux()` / `model.get_aux()`：统一的中间量记录与读取接口；
- `model.get_variable_graph()`：提取学习到的变量物理图边权；
- `model.get_spatial_beta()`：提取各层邻站注入强度 β（residual 模式）。

**（5）KNN 基线的向量化实现（一个被反复证伪的优化过程）**

KNN 基线在缺失强度梯度实验中是耗时瓶颈，本作品对其做了向量化改造。这个过程本身有方法论价值，值得记录。

sklearn 的 `KNNImputer` 使用 `nan_euclidean` 距离，该距离**带 NaN、不满足度量公理**，因此无法使用 KD-Tree / Ball-Tree 加速；对 6 维这种低维数据，sklearn 只能在 Python 层逐对暴力计算。实测 59,328 行 × 6 列的 transform 单次耗时 54 秒（其中 `NearestNeighbors(metric="euclidean")` 仅需 0.97 秒 —— `nan_euclidean` 慢了 120 倍）。

改造过程中有两条"捷径"被实测否决：

| 思路 | 预期 | 实测结果 |
|---|---|---|
| KD-Tree 抄近路（先补均值再用普通欧氏距离） | 54s → 1s | **否决**：`nan_euclidean` 带 `C/n_valid` 缩放（`n_valid` = 双方共同非缺失维度数），查询行缺 1 个变量时系数在 1.2 与 1.0 间跳变，近邻排序改变，前 5 近邻集合完全不同 |
| 朴素三维张量 `(b,d,C)` 广播 | 语义正确即可 | **否决**：正确但比矩阵乘法慢 25 倍（4.94s vs 0.20s），整轮超过 20 分钟，比 sklearn 还慢 |

最终解法利用了掩码的可分离性。记 `both[i,j,c] = va[i,c]·vt[j,c]`（查询侧掩码 × donor 侧掩码），只要**先把掩码预乘到数据上**，求和就能整体写成矩阵乘法：

```
Σ_c (a_c − b_c)²·both[c]
  = (a²·va) @ vtᵀ  −  2·(a·va) @ (b·vt)ᵀ  +  va @ (b²·vt)ᵀ
```

这一招把原本必须用三维张量的计算全部化为 `(b,C) @ (C,d)` 的矩阵乘，彻底消掉 `(b,d,C)` 数组。

**正确性**：与 sklearn 在 5 组不同训练/测试规模、不同缺失率、k ∈ {1,3,5,7} 的共 20 种组合下逐一比对，缺失位最大差异 **1e-9 ~ 1e-13**（浮点舍入量级），可视为完全一致。

**性能**：单次 transform 从 54 秒降到 45 秒，12 个网格点约 9 分钟。

另外两个必须复刻的 sklearn 语义细节（否则结果会偏）：
1. **逐列独立处理**：donor 池是"训练集中**该列**非缺失的行"，而非"整行完整的行"。初版误按整行处理，偏差达 0.5~2.2。
2. **距离基于原始缺失模式**：sklearn 先算好整块距离矩阵再逐列填值，所以第 2 列的距离不会因第 1 列已被填上而改变。若原地写入，对"一行缺多列"的情况偏差约 0.03。

此外还需处理两种退化情形：某列在训练集中全缺时用该列均值兜底；某行与所有 donor 都无共同非缺失维度时（`n_valid = 0`）也用该列均值填补，而非报错。

## 五、应用成效

### 1. 实验设置

> **口径声明（重要）**：本文件所载全部指标，来自 2025 年 8 月 21 日–9 月 20 日的 **30 天逐小时原型实验**（华北 8 站、6 个气象要素、共 744 小时）。这是一个**用于验证方法与代码正确性的最小可行性实验**，样本量偏小，**不应被理解为最终成绩**。正式比赛提交前需按 §六.2 的规划扩大时间跨度与站点规模后重跑。

**数据**：NASA POWER 逐小时观测，2025 年 8 月 21 日–9 月 20 日，共 744 小时；华北 8 站，6 个气象要素（T2M / QV2M / WS10M / PS / PRECTOTCORR / SWGDN）。数据缓存指纹 `362550396a0adcf5`。

**模型配置**：窗口长度 72 小时，步长 12 小时，隐藏维度 64，3 层时空块，卷积核 5，空间聚合模式 `residual`。

**训练配置**：**统一 400 轮固定预算**（`--epochs 400 --patience 400`，即**关闭早停**），批大小 16，学习率 2e-3，随机种子 42。按 best-val 选择最终权重。

> **为什么要关闭早停**：验证集只有 9 个窗口，val 曲线噪声较大。实测用默认 `patience=12` 时，完整模型在第 166 轮就误触发早停（val 0.185），而同一批的其他配置跑满 300 轮（val 0.134）——各组**实际训练轮数不一致**，导致出现"去掉某模块反而更好"的假结论。改为固定预算后，6 组全部跑满 400 轮，指标才可横向比较。

**数据划分**：对整段序列切窗（57 个窗口），按时间顺序 7:1.5:1.5 划分为 **训练 39 / 验证 9 / 测试 9** 个窗口。

**缺失设置**：MCAR 率 0.15，连续段生成概率 0.30，最长连续缺测 24 小时（= 窗口的 1/3，满足 §3.3 的比例约束）。测试集实际缺口占比 0.192。

**空间图参数**：高斯核带宽 σ = 350 km；行归一化后自环权重均值 0.274。

**评测口径**：R² 以「缺口处均值填充」为基线，即 R² = 1 − SSE_model / SSE_meanfill。因此 R² > 0 的含义是「比均值填充好」，而非通常意义上的拟合优度。

> **可追溯性说明**：每次运行的完整配置（数据指纹、窗口/步长、窗口数划分、缺失参数、模型结构、训练超参含实际轮数与是否早停、物理约束、参数量）都会写入 `metrics*.json` 的 `run_config` 字段。上表所有数字均可在 `metrics.final.json` / `metrics.ablation.json` 中逐项核对。

### 2. 成果展示

**表 1：五模型性能对比（2025 年 8 月 21 日–9 月 20 日，744 小时，华北 8 站 6 要素）**

| 模型 | MAE | RMSE | R² | 参数量 |
|---|---|---|---|---|
| **GRIN-lite（本作品）** | **6.0671** | **19.0293** | **+0.9593** | **15,661** |
| LSTM（同参数规模） | 9.6722 | 36.1889 | +0.8528 | 15,959 |
| 线性插值 | 10.4164 | 46.8116 | +0.7537 | — |
| 均值填充 | 33.1027 | 83.0383 | +0.2249 | — |
| KNN | 37.1686 | 109.2796 | −0.3423 | — |

**关键结论**：

1. **相对同参数规模 LSTM**：MAE 降低 37.3%，RMSE 降低 47.4%，R² 提升 0.1065。参数量偏差仅 +1.90%。这验证了创新点二——在相同参数预算下，卷积结构优于循环结构。

2. **相对传统方法**：R² 为线性插值的 1.27 倍。KNN 的 R² 为**负值**（−0.3423），即其插补结果**比直接填训练集均值还差**。这一现象的原因值得说明：KNN 将每个时间步视为独立样本，完全丢弃了时间顺序信息；在连续缺测段上，它只能依靠变量间关系外推，而气压、比湿等变量的量纲差异又会主导欧氏距离，导致近邻选择失效，最终在时间维度上完全没有依据。

3. **模型规模**：参数量 15,661，占 10 万预算的 15.7%，符合轻量化目标。

### 3. 消融实验

为定位各模块的实际贡献，开展了逐项消融。**6 组配置全部在 `residual` 聚合下运行**，共用同一份数据、同一个随机种子（42）、同一套掩码生成顺序，以及**完全相同的 400 轮训练预算**（关闭早停）。因此任意两组之间可以直接相减，无需分批说明。

**表 2：消融实验结果**（单批次，同种子同掩码同预算，可直接横向比较）

| 配置 | MAE | RMSE | R² | ΔR²（相对完整模型） |
|---|---|---|---|---|
| **完整模型（residual 聚合）** | **6.0671** | **19.0293** | **+0.9593** | — |
| 去除物理约束（time_smooth） | 6.0068 | 19.0988 | +0.9590 | −0.0003 |
| 去除站点空间图 | 6.0116 | 20.3648 | +0.9534 | −0.0059 |
| 物理约束权重加大至 0.2 | 6.2385 | 20.5196 | +0.9527 | −0.0066 |
| 去除变量物理图 | 8.7007 | 31.7787 | +0.8865 | −0.0728 |
| 改用上游原版平均聚合（avg） | 14.9910 | 53.0513 | +0.6837 | **−0.2756** |

> 各组完整配置与逐变量指标见 `metrics.ablation.json`（由 6 份 `metrics.fin_*.json` 合并，每份都带 `run_config`）。

**分析**：

1. **空间聚合方式是决定性因素，且是唯一的大幅影响项**。将聚合方式从上游原版的 `avg` 改为 `residual`，R² 从 0.6837 提升到 0.9593（**+0.2756**），是所有改动中影响最大的，量级是其他项的 4~900 倍。这一发现过程具有方法论价值：若仅观察总体指标，很容易误判为「图结构整体无效」从而错误地移除整个空间图分支；而逐项消融揭示出真正的问题在于**聚合权重的分配方式**，而非图结构本身。

2. **变量物理图贡献明确为正**。去除后 R² 从 0.9593 降至 0.8865（−0.0728），MAE 上升 43%。这是除聚合方式外贡献最大的模块，说明「以物理相关性初始化、再让数据微调」的变量间消息传递确实带来了增益。

3. **站点空间图贡献为正，但幅度很小**。去除后 R² 下降 0.0059、RMSE 上升 7%。方向明确但量级不大——这与 §3.4 的分析一致：8 个站点相距 110~1056 km，在 72 h 窗口内站间气温相关中位数 0.86，邻站能提供的新信息有限。**这恰恰印证了 `residual` 设计的合理性**：β 可学习，模型自己把邻站的作用压到很小的幅度，而不是像 `avg` 那样强制以邻站为主。

4. **物理约束（时间平滑）贡献为正但很微弱**。完全去除后 R² 仅下降 0.0003（MAE 反而略降 0.06，两项指标方向不一致，属噪声量级）；把权重从 0.05 加大到 0.2 后 R² 下降 0.0066，说明**当前权重已接近合适区间，继续加大反而有害**。结论：该约束有微弱正贡献，但不构成本作品的主要增益来源。

5. **贡献排序**：空间聚合方式（−0.2756）≫ 变量物理图（−0.0728）> 物理约束权重（−0.0066）≈ 站点空间图（−0.0059）> 物理约束开关（−0.0003）。

> **方法论备注**：本表的结论是**修正了早停缺陷之后**才得到的。在统一训练预算之前，完整模型因提前早停（166 轮 vs 其他组 300 轮）而指标偏低，一度出现「去掉物理约束、去掉空间图反而更好」的假结论。这一排查过程说明：**消融实验中，各组的训练预算必须严格一致，否则指标差异会混入训练程度的差异。**

### 4. 可解释性分析

所有中间量均以原始张量形式落盘于 **`auxiliary.final.npz`**（含 `variable_graph`、`spatial_beta`、`embed`、`block0~2`），并附 `meta_json` 记录产生它的运行配置，可直接复算。

**（1）变量物理图（学习结果）**

模型训练后输出的变量间边权矩阵（行归一化，`auxiliary.final.npz` 的 `variable_graph` 字段）中，边权最高的几对为：

| 变量对 | 边权 | 物理含义 |
|---|---|---|
| QV2M × SWGDN | 0.398 | 比湿 × 短波辐射——辐射驱动蒸发，是水汽的主要来源 |
| WS10M × PRECTOTCORR | 0.354 | 风速 × 降水——同受天气系统过程支配 |
| WS10M × PS | 0.285 | 风速 × 气压——气压梯度决定风 |
| T2M × QV2M | 0.213 | 温度 × 比湿——饱和水汽压随温度上升 |

这几对关系在物理上都是成立的，说明「以物理相关性初始化、再让数据微调」的变量图确实学到了**可解释的物理结构**，而非纯噪声。这也是变量图消融中贡献为正（ΔR² = −0.0728）的直接原因。

**（2）各层邻站注入强度 β 的层级规律**

对训练后的模型提取各层 β 值（`auxiliary.final.npz` 的 `spatial_beta` 字段）：

| 层 | β 值 | 解读 |
|---|---|---|
| blocks.0 | **+0.0949** | 与初始值 0.1 相当，温和利用邻站信息 |
| blocks.1 | +0.0002 | 完全归零，认为邻站无增量贡献 |
| blocks.2 | −0.1043 | 略偏负向，主要依靠本站 |

**这一结果呈现出清晰的层级规律：浅层利用邻站信息，深层依靠本站自身特征。**

物理解释：浅层网络仍在处理相对原始的输入信号，此时邻站的低频背景（如区域天气系统的整体演变）具有参考价值；深层网络已在提取本站的精细时序结构，此时邻站信息不再有增益，模型便把权重压到接近零。

β 取到负值的含义是：模型主动**反向**利用邻站与本站的差异（即"邻站升高而本站降低时，本站更应降低"），可解读为一种局地偏差修正机制；幅度很小（|β| < 0.11），说明这是一种微调而非主导信号。

> **该规律的可重复性**：在两组独立训练（不同超参预算）中，浅层 β 均为正、深层 β 均归零或转负，模式稳定。这说明它反映的是数据本身的结构，而非某次训练的偶然。

**这一发现表明模型自主学会了"何时该参考邻站、何时应依靠自身"，无需人工设计规则。** 相比固定权重的空间图，这种自适应的信息利用方式更为稳健，也更具可解释性。

### 5. 日变化诊断

`diurnal.final.png` 左图（**北京站单站**）展示了气温的日变化轮廓对比：插补曲线与真值曲线高度重合。该站真值峰值为 **23.1 °C（13 时）、谷值 12.7 °C（5 时）**。测试段真值的 **8 站平均**日变化轮廓为**峰值 23.7 °C（13 时）、谷值 15.9 °C（5 时），日较差 7.8 °C**，插补曲线在**相位与幅度上均与真值一致**。

该图是本作品的主要调参诊断依据。在项目早期阶段，模型仅训练 1 个 epoch 时，插补曲线呈现明显的"方波"形态（在平台间跳变，完全没有日变化特征），由此迅速定位为欠训练问题；提升训练轮次后，曲线形态随即与真值吻合。相比仅观察 MAE/R² 等标量指标，这一可视化手段能更直接地判断模型是否学到了气象规律。

### 6. 指标口径的重要说明

需要特别说明 MAE 指标的一个统计特性，否则容易产生误读：

**MAE 是绝对误差，会被大量纲变量主导。** 气压（PS）的量纲为 10⁵ Pa，而降水（PRECIPTOTCORR）的量纲为 10⁻¹ mm/hr。若直接对所有变量求平均 MAE，结果几乎完全由气压决定，不具物理可比性。

因此**跨变量平均的 MAE 不能作为模型优劣的唯一判据**。本作品在报告中同时给出三类指标：

1. **R²**：以缺口处真值均值为基准，可直接理解为"比均值填充好多少"，是最具物理意义的汇总指标；
2. **逐变量 MAE / RMSE**（存储于 `metrics.final.json` 的 `per_var_MAE` / `per_var_RMSE` 字段）：用于诊断各要素的插补质量；
3. **跨变量平均 MAE**：仅用于观察趋势，报告中需标注其局限性。

以本作品结果为例：线性插值的跨变量平均 MAE（10.42）看起来相当低，甚至接近 GRIN-lite（6.07）的同一量级，但其 R²（0.7537）显著低于 GRIN-lite（0.9593）。这一差异正源于线性插值对气压这类平滑变量的插值精度极高——**气压的逐变量 MAE 仅 0.0344**（而 GRIN-lite 为 0.5289），从而把跨变量平均 MAE 大幅拉低。

**逐变量 MAE 对照**（`metrics.final.json` 的 `per_var_MAE` 字段）：

| 模型 | T2M | QV2M | WS10M | PS | PRECTOTCORR | SWGDN |
|---|---|---|---|---|---|---|
| **GRIN-lite** | **0.7216** | **2.9921** | **0.2703** | 0.5289 | **0.1446** | **31.07** |
| LSTM | 1.7834 | 4.5092 | 0.6227 | 0.5606 | 0.2923 | 49.19 |
| 线性插值 | 0.8715 | 3.7150 | 0.4505 | **0.0344** | 0.2268 | 55.92 |
| 均值填充 | 5.6900 | 13.4085 | 1.4860 | 3.9701 | 0.4998 | 169.96 |
| KNN | 5.3013 | 13.0155 | 1.6269 | 4.2645 | 0.5513 | 194.08 |

可以看到：**GRIN-lite 在 6 个变量中的 5 个上都是最优**，唯独在气压上不如线性插值——而恰恰是气压这个量纲最大的变量主导了跨变量平均 MAE。**因此若不看 R² 与逐变量指标，仅凭跨变量平均 MAE 会得出错误结论。**这也是本作品坚持同时报告三类指标的原因。

### 7. 缺失强度梯度实验

上面所有对比都是在**单一缺失强度**（MCAR 0.15 + 连续段 24 h）下做的。为考察方法在**不同缺测严重程度**下的稳健性，进一步做了梯度实验：以 MCAR 率（5% / 15% / 30%）× 最长连续缺测段（6 / 12 / 24 / 36 小时）构成 12 个网格点，**模型权重固定**（沿用基准强度下训练的那一份），仅改变评测掩码——这样性能差异纯粹归因于缺失模式，不含训练随机性。

结果落盘于 `missing_gradient.json` / `missing_gradient.md` / `missing_gradient.png`。

**关键结论**：

1. **GRIN-lite 在全部 12 个网格点上均为最优**，R² 稳定在 **+0.942 ~ +0.977** 区间，随缺失强度上升仅缓慢下降（最差格点仍比最好格点低 0.035）。

2. **线性插值在长连续缺测下急剧崩塌**。缺口长度 6 h 时它的 R²（+0.952）与 GRIN-lite 几乎持平；但缺口拉长到 24 h，R² 骤降到 **+0.343**（MCAR 5%）。这正是插值的本质缺陷——缺口越长，插值点离两端观测越远，误差越大，且它对缺口的填补完全不含任何气象规律。

3. **GRIN-lite 的稳健性来自它同时利用了时间上下文与站点/变量间关系**，因此缺口长度增加时性能衰减远小于插值类方法。这一结果从"缺失强度维度"独立佐证了 §5.2 的结论。

> **一个必须如实说明的反向证据**：若改用**跨变量平均 MAE**（`missing_gradient.md` 表 A）排序，结论会反转——在 **6 h / 12 h 的短缺口**格点上，线性插值的 MAE（4.5~5.9）反而略优于 GRIN-lite（4.9~6.2）。这与 §5.6 的口径说明完全一致：跨变量平均 MAE 被气压（量纲 1e5 Pa）主导，而线性插值在短缺口 + 平滑变量上极强。因此**本表以 R² 为主判据**，MAE 仅作趋势参考。换言之：**本模型的优势不在短缺口，而在长缺口与高缺测率**——这也正是它相对传统方法的价值所在。

> **⚠ 实验设计上的一个教训（如实记录）**：本实验首次运行时，训练窗口只用了序列前 70% 且步长取 72 h，训练集仅 13 个窗口，导致模型严重欠拟合，GRIN-lite 的 R² 一度全为**负值**。排查后确认不是模型能力问题，而是实验设计缺陷（训练样本量不足），已改为与主实验完全一致的切窗与划分口径。此外还发现并修复了一处 checkpoint 保存的 bug（`best` 被误赋为 0，导致保存的是第 1 轮随机权重）。**这两处问题都是通过"结果与预期严重不符时坚持追根因"发现的，而不是靠调参掩盖。**

## 六、总结与展望

### 1. 经验总结

本作品构建了一套面向自动气象站缺测数据的轻量化智能插补方案，通过"站点空间图 + 变量物理图 + 深度可分离膨胀卷积"的组合，在 10 万参数量预算内实现了多站点多要素联合插补。在真实逐小时气象数据上，R² 达到 0.9593，较同参数规模 LSTM 提升 0.1065，MAE 降低 37.3%，验证了轻量卷积结构在气象数据插补任务上的有效性。

**实施过程中的主要经验与教训**：

1. **消融实验必须逐项开展，且需关注每一项的单独贡献。** 本作品最重要的结构性改进（空间聚合方式由 `avg` 改为 `residual`）正是通过逐项消融发现的。若仅观察总体指标，极可能误判为"空间图整体无效"并错误删去该模块，从而丢失一个实际有价值的组件。

2. **构造图结构时必须检查自环权重占比。** 行归一化后的自环权重直接反映本站信息在聚合后的保留比例。当该值低于 0.5 时应当警惕：聚合操作会主导特征表示，稀释本站信号。本作品已在图构建函数中加入该诊断输出与自动警告，可帮助使用者及早发现此类问题。

3. **为外部信息注入引入可学习的强度系数，比人工二选一更为稳健。** 本作品采用 `h = h + β·(agg − h)` 的形式，让模型自行决定 β。当外部信息无用时可自动退化为 0，避免了"用或不用"这一非此即彼的人工决策。

4. **小样本条件下，「模块是否有用」的结论很容易被训练不充分污染。** 本作品训练窗口 39 个、参数量 15.7k，样本量确实偏紧。在修正早停缺陷之前，实验一度给出「变量物理图有害、物理约束有害」的结论；把各组的训练预算统一为 400 轮后，两者的 ΔR² 都转为负向（即均为正贡献）。这说明：**在样本量紧张时，判断某个模块是否有效，前提是各组必须训练得同样充分**，否则会把「训练不够」误读为「模块有害」。

5. **实验推进应遵循"先小后大"的节奏。** 本作品在实施初期曾直接拉取整年数据（8784 小时）进行实验，导致基线计算量过大、单次实验耗时过长。调整为先以 3 天数据验证流程与输出形态，确认无误后逐步放大至 30 天，显著提升了迭代效率。

### 2. 未来规划

**（1）物理规律约束的深入探索。**
当前时间平滑约束的贡献为正但极其微弱（ΔR² = +0.0003，属噪声量级），而把权重从 0.05 加大到 0.2 后反而变差（ΔR² = −0.0066）。说明该约束的形式与权重都还有优化空间，改进方向包括：
- 通过权重搜索确定最优系数（当前 0.05 已接近合适区间，但 0.2 已过强，需在 0.02~0.15 之间细扫）；
- 改为按变量差异化加权（日变化周期约束对气温与辐射有效，对降水可能有害）；
- 实现日变化周期约束的完整版本，利用逐小时数据的相位信息（当前只启用了 `time_smooth`，其余约束仍为骨架）。

**（2）变量物理图的进一步优化。**
变量物理图已是除聚合方式外贡献最大的模块（ΔR² = −0.0728 即去除后损失 0.0728），但仍有提升空间：当前边权由相关性初始化、靠 39 个训练窗口微调，小样本下估计可能不稳。改进方向包括：扩大训练数据量、对变量图施加稀疏正则（当前 6×6 矩阵接近稠密）、或引入物理机理确定的先验边权作为软约束。

**（3）连续缺测场景的专项验证。**
本作品当前设置的最长连续缺测为 24 小时（窗口 72 小时的 1/3）。空间图的价值应在**长缺口跨站互补**场景下更为显著——当本站缺失时间足够长时，邻站信息成为唯一的推断依据。后续实验将把连续缺测长度扩展至 48–72 小时（窗口同步扩展至 144–216 小时），验证 β 是否会随缺口增长而增大。

**（4）缺失强度梯度实验的进一步扩展。**
该实验已完成（结果见 §5.7 与 `missing_gradient.*`），在 12 个网格点上确认了「模型优势随缺口增长而扩大」的规律：线性插值在 24 h 连续缺口下 R² 跌至 +0.343，而 GRIN-lite 仍保持 +0.942 以上。后续可在此基础上扩展两个维度：
- 把连续段长度上界推到 48–72 h（需先把 `--window` 放大到 144 h 以上，见 §四.2(4) 的约束说明）；
- 加入「跨站互补」的定向设计——人为只挖掉单站的整段数据而保留邻站，以直接量化空间图在长缺口下的贡献。

**（5）MERRA-2 数据通道的完整实现。**
MERRA-2 原生接口可提供更完整的变量集（含比湿、地表气压），对本作品的多变量联合建模更有价值。当前其 OPeNDAP 返回格式解析尚未实现（代码中为显式占位，调用即抛出说明性异常），待获取真实返回样本后补完。**此处刻意不编写未经实测验证的解析代码**，以避免产生看似可用但实际错误的结果。

**（6）质量评估与可视化系统。**
在算法验证完成后，将构建包含数据概览、缺测检测、插补结果、质量评估、模型对比五个模块的可视化界面，形成从算法到应用的完整闭环。

### 2. 代码与模型

**（1）环境依赖**

```
python >= 3.10
numpy >= 2.0
torch >= 2.0
scikit-learn >= 1.3
matplotlib >= 3.7
requests >= 2.28
```

**（2）运行流程**

```bash
# 第 1 步：训练主模型（本文件全部指标即由此命令产出）
#   --dump_aux 额外导出 aux.fin_final.npz（变量图 / β / 中间特征）
python -u grin_imputation.py --source power_hourly \
    --start 20250821 --end 20250920 \
    --window 72 --stride 12 --block_maxlen 24 \
    --spatial_mode residual --phys time_smooth \
    --epochs 400 --patience 400 --hidden 64 --n_layers 3 --batch 16 --lr 2e-3 \
    --seed 42 --tag fin_final --dump_aux

# 第 2 步：运行传统方法基线（线性插值 + KNN，复用主程序的数据与掩码）
python -u baseline.py --source power_hourly \
    --start 20250821 --end 20250920 \
    --window 72 --stride 12 --block_maxlen 24 --seed 42 --tag fin_final

# 第 3 步：运行同参数规模 LSTM 基线（超参须与第 1 步完全一致）
python -u LSTMbaseline.py --source power_hourly \
    --start 20250821 --end 20250920 \
    --window 72 --stride 12 --block_maxlen 24 \
    --epochs 400 --patience 400 --hidden 64 --n_layers 3 --batch 16 --lr 2e-3 \
    --seed 42 --tag fin_final
```

> **三条命令必须同 `--seed`、同 `--window`/`--stride`/`--block_maxlen`**，否则掩码不一致，对比就不公平。第 2、3 步会自动把结果合并进第 1 步生成的 `metrics.fin_final.json`，形成完整的五模型对比表。
>
> 说明：`--tag` 会产生 `metrics.{tag}.json`、`best_grin.{tag}.pt` 等带后缀的产物，互不覆盖；正式提交时**建议始终带 tag**，便于多组实验并列。本文件最终使用的 tag 为 `fin_final`，归档后的产物名为 `metrics.final.json`、`auxiliary.final.npz`。

**（3）消融实验**

```bash
# 各消融配置（仅需在基准命令上追加对应开关）
--ablate_no_spatial              # 去除站点空间图
--ablate_no_var                  # 去除变量物理图
--phys_ablate                    # 去除全部物理约束
--spatial_mode avg               # 使用旧版加权平均聚合
--phys_weight time_smooth=0.2    # 调整时间平滑权重
```

**（5）关键参数速查**

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--source` | `merra2` | 数据源（`merra2` 需 Earthdata 凭据；实测可用建议用 `power_hourly`） |
| `--window` | 72 | 窗口长度（小时），须 ≥ 2×`block_maxlen` |
| `--stride` | 24 | 滑窗步长（小时）。**本文件实验实际使用 12**（默认值仅作为保守起点） |
| `--block_maxlen` | 24 | 最长连续缺测小时数，须 ≤ 0.5×`window` |

| `--sigma_km` | 350 | 空间图高斯核带宽 |
| `--phys` | `["time_smooth"]` | 启用的物理约束列表 |

| `--patience` | 12 | 早停耐心值。**验证集较小时务必设为 `--epochs` 以关闭早停**，否则各组实际训练轮数不一致，会污染消融对比（本文件实验用 `--patience 400`） |

| `--tag` | `""` | 实验标签，用于区分多组实验产物 |
| `--dump_aux` | 关 | 导出可解释性中间量到 `aux{tag}.npz`（含变量图、各层 β） |
